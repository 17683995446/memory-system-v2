# 第9步：绘制全局单向数据流总图

## 全局单向数据流

```
原始用户输入 / 工具执行结果
        ↓
信息清洗过滤层
        ↓
记忆分类分发层
        ↓
┌───────┴───────┐
↓               ↓               ↓
L1瞬时记忆     L2向量记忆     L3事实记忆
        ↓               ↓               ↓
    任务触发召回
        ↓
    记忆融合推理
        ↓
    任务闭环复盘
        ↓
记忆治理更新 / 遗忘
```

## 数据流特性
- 单向流动，无循环依赖
- 每个节点职责单一
- 所有节点可独立插拔
- 全流程可监控可追溯
