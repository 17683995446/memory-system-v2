# 第11步：定义模块间调用规则

## 模块依赖关系图

```
信息预处理模块
        ↓
分层存储模块
        ↓
智能召回模块 ← 记忆自治治理模块
        ↓
复盘迭代模块 → 记忆自治治理模块
```

## 单向依赖规则

### 依赖方向
1. 信息预处理模块 → 分层存储模块
2. 分层存储模块 → 智能召回模块
3. 智能召回模块 → 复盘迭代模块
4. 记忆自治治理模块 → 分层存储模块、智能召回模块

### 禁止反向依赖
- 分层存储模块 不能调用 信息预处理模块
- 智能召回模块 不能调用 分层存储模块（除查询外）
- 复盘迭代模块 不能调用 信息预处理模块

### 接口约定
- 所有模块间通过标准化接口调用
- 数据格式统一
- 错误处理规范化
