# 第14步：制定分层存储硬性分发规则

## 智能分发规则（硬编码，不依赖模型）

### L1 瞬时记忆分发规则
**分发条件**
- 单任务临时交互
- 实时执行步骤
- 中间计算结果
- 当前会话的上下文

**分发逻辑**
```
if 数据属于当前任务临时上下文:
    存入 L1
```

### L2 情景记忆分发规则
**分发条件**
- 场景经验
- 操作习惯
- 历史问题解决方案
- 用户偏好记录

**分发逻辑**
```
if 数据具有跨会话参考价值 and 非结构化:
    存入 L2
```

### L3 事实记忆分发规则
**分发条件**
- 固定规则
- 用户固有信息
- 业务实体关系
- 标准化流程
- 可验证的事实

**分发逻辑**
```
if 数据是结构化事实 or 业务规则:
    存入 L3
```
