# 第18步：搭建记忆自治治理框架

## 记忆自治治理框架

### 动态遗忘能力

#### L1 遗忘策略
- 任务结束自动清空
- 任务超时自动清空

#### L2 遗忘策略
- 低频数据自动清理（如30天未访问）
- 过期数据自动归档
- 存储容量超限自动淘汰最不常用数据

#### L3 遗忘策略
- 无自动删除
- 仅人工+双校验更新

### 冲突更新能力
- 新旧事实冲突时，以「时间最新 + 可信度校验」为唯一判定依据
- 覆盖旧数据
- 留存版本快照

### 防投毒防护能力
- 识别恶意诱导篡改记忆
- 识别虚假灌输信息
- 拦截写入并标记风险
- 关键词+逻辑冲突双校验

### 冗余清理能力
- 定时清理重复记忆
- 定时清理无效归档数据
- 维持系统轻量化
