# 第7步：研讨三层记忆层级划分逻辑

## 分层维度
从「信息生命周期 + 使用频率 + 数据形态」底层维度分层，而非行业主观经验分层

## L1 瞬时工作记忆
### 定位
单任务实时运行上下文

### 核心特性
- 低延迟
- 易销毁
- 不落地
- 高读写

### 适用场景
- 当前任务的临时交互
- 实时执行步骤
- 中间计算结果

## L2 情景经验记忆
### 定位
非结构化场景经验、用户偏好、历史交互

### 核心特性
- 语义检索
- 跨会话
- 模糊匹配
- 动态淘汰

### 适用场景
- 场景经验
- 操作习惯
- 历史问题解决方案

## L3 永久事实记忆
### 定位
结构化规则、实体关系、固定事实、业务范式

### 核心特性
- 精准查询
- 逻辑推理
- 不可自动销毁
- 迭代更新

### 适用场景
- 固定规则
- 用户固有信息
- 业务实体关系
- 标准化流程
