# 第8步：输出层级对照表

## 三层记忆对照表

| 记忆层级 | 底层本质 | 存储载体 | 生命周期 | 核心特性 |
|---------|---------|---------|---------|---------|
| 瞬时工作记忆（L1） | 单任务实时运行上下文 | 内存缓存 + 会话窗口 | 单次任务周期 | 低延迟、易销毁、不落地、高读写 |
| 情景经验记忆（L2） | 非结构化场景经验、用户偏好、历史交互 | 向量数据库 | 中长期留存、动态淘汰 | 语义检索、跨会话、模糊匹配 |
| 永久事实记忆（L3） | 结构化规则、实体关系、固定事实、业务范式 | 图数据库 + 结构化数据库 | 永久留存、迭代更新 | 精准查询、逻辑推理、不可自动销毁 |

## 存储技术选型

| 层级 | 技术选型 | 选型理由 |
|-----|---------|---------|
| L1 | 原生内存字典 + 队列 | 无需中间件，零成本，低延迟 |
| L2 | FAISS | 轻量化向量库，低资源、高检索速度 |
| L3 | Neo4j + SQLite | Neo4j适配三元组推理，SQLite存储配置 |
