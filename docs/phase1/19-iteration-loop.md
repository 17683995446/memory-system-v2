# 第19步：设计复盘迭代闭环流程

## 复盘迭代闭环流程

### 任务闭环后自动复盘
**复盘内容**
- 总结成功范式
- 总结失败原因
- 记录异常场景
- 评估记忆召回有效性

### 经验提炼为规则
**转化路径**
1. 识别可复用经验
2. 抽象为通用模式
3. 转化为结构化三元组
4. 增量更新至L3事实记忆

### 优化召回权重
**优化方向**
- 根据使用反馈调整匹配权重
- 更新关键词匹配策略
- 调整相似度阈值
- 优化Top-K参数

## 闭环流程图
```
任务执行
    ↓
任务完成
    ↓
自动复盘
    ↓
    ├─→ 成功范式 → 提炼规则 → 更新L3
    ├─→ 失败教训 → 记录案例 → 更新L2
    └─→ 召回评估 → 权重优化 → 改进召回
```
