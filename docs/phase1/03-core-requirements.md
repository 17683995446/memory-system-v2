# 第3步：拆解第一性底层需求

## 5项原子核心诉求

### 1. 瞬时任务
- 需要低延迟、高可用的临时上下文承载
- 单次任务周期内快速读写
- 任务结束即销毁

### 2. 经验复用
- 需要语义匹配、跨会话的情景经验沉淀
- 同类场景快速参考
- 用户偏好积累

### 3. 事实固化
- 需要结构化、可推理、不可随意篡改的永久知识
- 实体关系明确
- 业务规则固定

### 4. 系统可控
- 必须具备过滤、校验、更新、遗忘、防投毒的自治能力
- 全流程可监控
- 异常可追溯

### 5. 工程落地
- 必须低成本、低冗余、单向依赖、可监控、可扩展
- 无过度技术堆叠
- 易于运维部署
