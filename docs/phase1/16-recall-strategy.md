# 第16步：设计多维度召回策略

## 多维度确定性召回策略

### L3 精准召回（最高优先级）
**检索路径**
- 实体匹配
- 关键词精确匹配
- 业务规则直接调用

**优先级**：最高，固定事实最可信

### L2 语义召回（中等优先级）
**检索路径**
- 向量相似度匹配
- 相似度阈值过滤
- Top-K结果返回

**优先级**：中等，经验参考

### L1 实时召回（当前任务）
**检索路径**
- 当前任务上下文直接获取
- 会话ID关联

**优先级**：根据任务相关性

## 召回组合策略
```
L3结果（固定事实） + L2结果（经验参考） + L1结果（当前上下文）
```
