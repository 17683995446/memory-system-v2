# 第12步：梳理原始数据风险点

## 原始数据三大风险

### 1. 噪音问题
**风险类型**
- 无意义闲聊（如"哈哈"、"嗯嗯"等）
- 重复文本
- 空白字符
- 无效指令（无法执行的内容）
- 测试数据

**危害**
- 占用存储空间
- 干扰召回结果
- 降低系统效率

### 2. 幻觉问题
**风险类型**
- 模型无依据输出
- 矛盾内容
- 虚假事实
- 逻辑不一致信息

**危害**
- 污染记忆库
- 导致错误决策
- 可信度下降

### 3. 隐私问题
**风险类型**
- 手机号
- 身份证号
- 地址信息
- 银行卡号
- 其他个人敏感信息

**危害**
- 数据泄露风险
- 合规问题
- 用户信任危机
