### 2. 核心功能实现

#### L1 瞬时工作记忆
- **存储**: 内存字典 + 队列
- **特性**: 低延迟、任务结束自动清理
- **接口**: add, get, clear

#### L2 情景经验记忆
- **存储**: FAISS向量索引（支持降级模式）
- **特性**: 语义检索、跨会话、动态淘汰
- **接口**: add, search, cleanup_old

#### L3 永久事实记忆
- **存储**: SQLite（结构化三元组）
- **特性**: 精确查询、版本管理、不可自动销毁
- **接口**: add, query_by_entity, query_by_keyword

#### 统一调度器 (MemorySystem)
- 智能分发规则（硬编码，不依赖模型）
- 多维度召回策略
- 会话隔离
- 统计信息

### 3. 技术特点

1. **分层解耦**: 各层独立，职责明确
2. **单向数据流**: 无循环依赖
3. **降级支持**: 不依赖可选库也能运行
4. **可配置**: 参数可调整
5. **可监控**: 完整日志系统
